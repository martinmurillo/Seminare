🌸 Configuración inicial

Para que el panel funcione desde cualquier dispositivo necesitas conectarlo a Supabase, una base de datos gratuita en la nube. Solo se hace una vez.

1. Crear cuenta gratuita Ve a supabase.com → "Start your project" → regístrate con Google o email.
2. Crear un proyecto Clic en New project → nombre: seminare-flores → elige contraseña → región West EU (Ireland) → Create project (espera ~1 min).
3. Ejecutar el SQL En tu proyecto → menú izquierdo → SQL Editor → New query → pega este código → clic Run: 
-- Tabla galería
CREATE TABLE gallery (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  label text,
  category text DEFAULT 'ramos',
  tag text,
  active boolean DEFAULT true,
  img_url text,
  created_at timestamptz DEFAULT now()
);

-- Tabla servicios
CREATE TABLE services (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  icon text,
  title text,
  description text,
  tag text,
  category text,
  active boolean DEFAULT true,
  sort_order int DEFAULT 0,
  created_at timestamptz DEFAULT now()
);

-- Tabla configuración
CREATE TABLE config (
  key text PRIMARY KEY,
  value text
);

-- Permisos de acceso
ALTER TABLE gallery ENABLE ROW LEVEL SECURITY;
ALTER TABLE services ENABLE ROW LEVEL SECURITY;
ALTER TABLE config ENABLE ROW LEVEL SECURITY;
CREATE POLICY "allow_all" ON gallery FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "allow_all" ON services FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "allow_all" ON config FOR ALL USING (true) WITH CHECK (true);

-- Bucket de imágenes
INSERT INTO storage.buckets (id, name, public) VALUES ('gallery', 'gallery', true) ON CONFLICT DO NOTHING;
CREATE POLICY "allow_upload" ON storage.objects FOR INSERT WITH CHECK (bucket_id = 'gallery');
CREATE POLICY "allow_select" ON storage.objects FOR SELECT USING (bucket_id = 'gallery');
CREATE POLICY "allow_delete" ON storage.objects FOR DELETE USING (bucket_id = 'gallery');
4. Obtener tus claves En Supabase → Project Settings (icono ⚙️ abajo a la izquierda) → API → copia la Project URL y la clave anon public.
